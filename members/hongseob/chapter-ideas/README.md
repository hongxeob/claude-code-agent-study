# chapter-ideas — 팀원용 안내

배운 챕터를 넣으면 **이번 주 각자 만들어볼 실습/도구 주제 후보**를 뽑아주는 스킬.
"뭐 만들지" 막힘을 없앤다.

> 만든 사람: 홍섭 · 스킬 본체: [`SKILL.md`](./SKILL.md)

## 주제를 정해주지 않는다

후보만 던진다. **고르고 만드는 건 사람 몫.** 각 후보엔 "이걸로 뭘 검증/의심해볼 수 있나"가 붙어, 그냥 만드는 게 아니라 검증 관점을 같이 준다.

## 쓰는 법

1. 챕터 학습 끝나면 **핵심 개념 몇 줄**을 스킬에 넣는다 (붙여넣기 or `chapters/chN/README.md` 경로).
2. "실습 주제 추천" / "주제 뽑아줘" 트리거.
3. 후보 4~6개(각 3줄) + 3인 분배 제안이 나옴.
4. 셋이 보고 **각자 만들 걸 고른다.**

## 특징

- 규모를 "1주차·발표 10분 안에 되는 것"으로 강제 → 과대 주제 안 나옴.
- 매 챕터 재사용.
