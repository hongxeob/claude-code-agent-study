# ch3 정리 — 서브에이전트 (재윤)

## 핵심
- 서브에이전트는 **컨텍스트를 격리**한다. 메인 대화를 안 더럽힌다.
- 대신 별도 컨텍스트라 **토큰을 추가로** 쓴다.

## 격리의 이득과 대가
- 이득: 메인 컨텍스트 절약, 작업 집중.
- 대가: 위임 프롬프트 + 결과 반환에 토큰 이중 지출 가능.

- 이유: 격리 좋다는 얘기만 많고 비용 얘기는 적음.
