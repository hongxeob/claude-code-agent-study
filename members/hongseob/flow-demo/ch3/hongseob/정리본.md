# ch3 정리 — 서브에이전트 (홍섭)

## 핵심
- 서브에이전트는 **병렬**로 여러 개 띄울 수 있다.
- 독립 작업이 여러 개면 병렬이 벽시계 시간을 줄인다. 의존 있으면 순차.

## 병렬 vs 순차
| | 병렬 | 순차 |
|---|---|---|
| 속도 | 빠름 | 느림 |
| 비용 | 토큰↑, 합치기 비용 | 단순 |
| 쓸 때 | 독립 작업 여럿 | 앞 결과가 뒤에 필요 |

## 발표 개념: **"언제 병렬이 이득인가"**
- 이유: 다들 병렬 써봤지만 손익분기 기준이 없음.
