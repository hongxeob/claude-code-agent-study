# ch3 — 서브에이전트

> 그 주 챕터 결과물 (chapter-merge 생성 · 개인 정리본 3개 통합 · 고정 4렌즈)

## 참여자별 (원문 보존)

### 홍섭 — 언제 병렬이 이득인가
- 병렬은 독립 작업이 여럿일 때 벽시계 시간을 줄인다. 의존 있으면 순차.
- 병렬은 토큰↑·합치기 비용이 따라온다.

### 재윤 — 격리의 대가는 토큰
- 서브에이전트는 컨텍스트를 격리해 메인을 안 더럽힌다.
- 대신 위임+반환에 토큰을 이중 지출할 수 있다.

### 준호 — 다중 심판 검증
- 리뷰어를 병렬로 붙여 교차검증. 하나가 놓친 걸 다른 하나가 잡는다.
- 단일 심판보다 놓침↓, 비용은 N배.

## 공통 (셋 다 짚은 것)
- 서브에이전트 위임은 유용하다 — 셋 다 동의.
- 병렬 위임엔 토큰 비용이 따른다는 인식도 공통.

## 흥미로운 것 (인상 깊었던 개념·경험)
- 준호: 다중 심판이 "AI 그냥 믿지 말자"는 스터디 철학과 정확히 맞물림.
- 홍섭: "병렬 손익분기"라는, 다들 안 재본 기준의 존재.

## 갈린 관점 (같은 걸 다르게 봄)
- 같은 서브에이전트를 홍섭=**성능**, 재윤=**비용**, 준호=**신뢰** 축으로 봄.
- 병렬(홍섭)은 다중 심판(준호)의 전제 — 검증도 결국 병렬 위임.

## 팀이 더 팔 것 (미해결 — 각 정리본 역질문)
- 병렬 손익분기 기준 (홍섭)
- 격리가 토큰 2배인지 측정 (재윤)
- 심판 기각 임계값 (준호)
- → 세 질문이 "병렬 서브에이전트의 토큰 대비 이득" 한 번 측정으로 상당 부분 겹침.
