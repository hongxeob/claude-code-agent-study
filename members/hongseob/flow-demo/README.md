# flow-demo — chapter-prep → chapter-merge 데모

ch3 "서브에이전트"를 가정한 **전체 플로우 예시** (3명 개인 정리 → 팀 통합).
실제 스터디 산출물이 아니라 스킬 동작을 보여주는 샘플.

## 흐름

```
[모이기 전] chapter-prep ×3 (개인)
  ch3/<이름>/정리본.md  +  ch3/<이름>/발표.html
        │
[스터디 중] chapter-merge (통합)
  ch3/README.md  +  ch3/발표-통합.html
```

## 파일

| 단계 | 파일 |
|---|---|
| 개인 정리본 | `ch3/hongseob/정리본.md`, `jaeyoon/…`, `junho/…` |
| 개인 발표 | `ch3/<이름>/발표.html` (스크롤 한 장, 2열 비교) |
| 팀 결과물(md) | `ch3/README.md` |
| 팀 통합 발표 | `ch3/발표-통합.html` (3관점 카드 + 종합) |

## 보는 법

html은 브라우저로 열면 됨 (자체완결, 외부 요청 0):
```
open members/hongseob/flow-demo/ch3/발표-통합.html
```

3명 발표 개념: 홍섭=성능(병렬), 재윤=비용(토큰), 준호=신뢰(검증) — 같은 도구 다른 축.
