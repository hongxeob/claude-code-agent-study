# chapter-merge — 개인 정리본 → 그 주 챕터 결과물

각자(chapter-prep로 만든) 개인 정리본 여러 개 → **챕터 README 한 개**(팀 결과물).
개인별 정리는 chapter-prep, 통합은 이 스킬. 둘은 다른 단계.

## 입력

- 참여자들의 개인 정리본: `chapters/chN/*/정리본.md` (전원 것 자동 수집) 또는 경로 목록.
- 챕터 번호/제목.

## 절차

1. 각 정리본을 읽는다.
2. **참여자별 섹션 보존** — 각자 발표 핵심 개념 + 요점을 사람별로 그대로 싣는다. (개인 생각·표현 뭉개기 금지)
3. **공통/차이 종합** — 여러 명이 겹쳐 짚은 것, 서로 갈린 관점만 뽑아 한 블록으로. 정리본에 실제로 있는 내용만 근거로 (새 주장 금지).
4. **미해결 모음** — 각 정리본의 역질문·`(확인 필요)`를 한데 모아 "팀이 더 팔 것"으로.
5. `chapters/chN/README.md`로 저장. `chapters/_TEMPLATE.md`가 있으면 그 틀을 따른다. 다른 참여자 섹션을 임의로 바꾸지 않는다.

## 규칙

1. **개인 통찰은 원문 보존.** 종합한답시고 개인 생각을 뭉개거나 대표 하나로 덮지 마라.
2. 공통/차이는 **정리본에 있는 것끼리만** 비교. 없는 사실·평가 지어내기 금지.
3. 요약은 "공통/차이 종합" 블록에만. 참여자별 섹션은 압축이 아니라 정리.
4. 저장 전 기존 `chapters/chN/README.md` 있으면 덮어쓰기 확인.

## 출력 구조 (챕터 README)

```
# chN — <챕터 제목>

## 참여자별 핵심
### 홍섭 — <발표 개념>
- 요점 ...
### 재윤 — <발표 개념>
- 요점 ...
### 준호 — <발표 개념>
- 요점 ...

## 공통으로 나온 것 / 갈린 관점
- 공통: ...
- 갈림: A는 ~, B는 ~

## 팀이 더 팔 것 (미해결)
- (각 정리본 역질문 모음)
```
