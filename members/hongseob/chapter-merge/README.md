# chapter-merge — 팀원용 안내

스터디 중(30~40분 단계), 각자 만든 **개인 정리본 여러 개를 그 주 챕터 결과물**
(`chapters/chN/README.md` + 통합 발표 `발표-통합.html`)로 통합하는 스킬.

> 만든 사람: 홍섭 · 스킬 본체: [`SKILL.md`](./SKILL.md)

## 개인 생각을 뭉개지 않는다

참여자별 섹션은 **그대로 보존**하고, AI는 **고정 렌즈로만** 종합한다.
"대표 요약 하나로 덮기"는 금지 — 각자 발표 개념·경험이 살아있어야 한다.
단순 책 정리가 아니라 **본인 경험·생각**이 재료다.

## 고정 렌즈 (매주 동일 → 주차 간 비교됨)

- **공통** — 셋 다 짚은 것
- **흥미로운 것** — 인상 깊었던 개념·경험
- **갈린 관점** — 같은 걸 다르게 봄
- **팀이 더 팔 것** — 미해결·궁금

## 스터디에서 쓰는 법

1. 모이기 전 각자 `chapter-prep`으로 개인 정리본을 만들어 둔다 (`chapters/chN/<이름>/정리본.md`).
2. 스터디 중 발표(1인 10분)가 끝나면 "챕터 결과물" / "정리본 합치기" 트리거.
3. 참여자별 섹션 + 4렌즈(공통/흥미로운 것/갈린 관점/팀이 더 팔 것)가 담긴 `chapters/chN/README.md` + 화면용 `발표-통합.html`이 나온다.
4. 확인 후 커밋 → 그 주 결과물로 등록. (`발표-통합.html`은 브라우저로 열어 공유)

## chapter-prep과의 차이

- **chapter-prep**: 모이기 전, **개인별** md+html (1인 발표용)
- **chapter-merge**: 스터디 중, **3개 → 하나** (팀 결과물)
