# study-wrapup — 스터디 마지막 10분 생각 정리

## 이건 거울이지 요약기가 아니다

말한 걸 **되비춰 적어줄 뿐**, 새 생각을 만들어주지 않는다.
쓰는 순서: **먼저 각자 말로 다 뱉은 뒤** 그 텍스트를 이 스킬에 넣는다. (생각을 대신하지 않기 위한 순서 고정)

## 입력

각자 말한 걸 그대로 붙여넣은 날것 텍스트. 형식 자유, 여러 명 한 번에 OK.

## 출력

발언자별로 6개 버킷 불릿 (1인 6줄 이내):

- **핵심 (오늘 배운 것)**
- **내 생각**
- **새로 안 것**
- **잘못 알던 것**
- **몰랐던 것 / 더 팔 것** (오늘 "내가 이걸 모른다"는 걸 깨달은 지점)
- **다음에 해볼 것** (관련 기술/액션 1~2개)

## 규칙 (어기면 학습 죽음)

1. **원문에 있는 표현만** 버킷에 재배치한다. 추론·미화·"더 나은 생각"으로 채우지 않는다.
2. 빈 버킷은 지어내지 말고 `(언급 없음)`으로 남긴다. **빈칸이 곧 아직 생각 안 한 부분** — 학습 신호다.
3. 특히 **"내 생각"·"잘못 알던 것"은 AI가 못 채운다.** 원문에 명시적으로 있을 때만 옮긴다.
4. 각 불릿은 한 줄, 발언자 본인 어투 살린다.
5. 끝에 **확인 질문 1개**: 애매하게 분류한 항목을 본인에게 되묻는다 (검증 유도). 답은 주지 않는다.

## 예시

입력:
```
민수: 오늘 SKILL.md 처음 봤는데 트리거가 description 한 줄로 정해진다는 게 신기.
난 프롬프트 길게 써야 잘 먹는 줄 알았는데 아니었네. 다음엔 커밋 메시지 스킬 만들어보고 싶다.
```

출력:
```
### 민수
- 핵심: 스킬 로딩 여부는 description 한 줄이 결정한다
- 내 생각: (언급 없음)
- 새로 안 것: 트리거는 frontmatter description으로 정해진다
- 잘못 알던 것: "프롬프트는 길어야 잘 먹는다"고 알고 있었음
- 몰랐던 것 / 더 팔 것: (언급 없음)
- 다음에 해볼 것: 커밋 메시지 생성 스킬 만들기

확인 질문: "프롬프트 길이" 얘기는 '잘못 안 것'으로 뒀는데, '내 생각'에 가까운가요?
```
