# study-wrapup — 팀원용 안내

스터디 마지막 10분, 각자 말한 생각을 **발표용 6버킷으로 받아 적어주는** 스킬.
AI/기술 얘기에만 매몰되지 않게, 각자 생각을 붙잡아 둔다.

> 만든 사람: 홍섭 · 스킬 본체: [`SKILL.md`](./SKILL.md)

## 이건 요약기가 아니라 거울

말한 걸 **되비춰 적어줄 뿐**, 새 생각을 만들어주지 않는다.
빈칸은 `(언급 없음)`으로 남는다 — 아직 생각 안 한 부분이 그대로 드러난다.

## 스터디에서 쓰는 법

1. **마지막 10분, 타이머 켬.** 각자 돌아가며 생각 말함 (오늘 배운 것 / 몰랐던 것 / 내 생각).
2. **발언을 텍스트로 확보** — Gemini 전사 마지막 10분 발췌, 또는 각자 Meet 채팅에 3~4줄.
3. **스킬 호출** — "생각 정리" / "랩업" 하고 그 텍스트 투입. (한 명이 3인분 몰아서 1번 추천 → 발언자별로 갈라줌)
4. **6버킷 출력** 보며 `(언급 없음)` 빈칸과 확인 질문을 각자 되짚음.
5. **결과 저장** → `insight/<이름>.md` 나 발표 준비물로.

## 꼭 지킬 것

- **말 먼저, 스킬 나중.** 순서 바뀌면 스킬이 생각을 대신하게 됨 = 학습 죽음.
- `내 생각`·`잘못 알던 것` 빈칸은 **직접** 채운다. AI 안 채운다.

## 출력 6버킷

핵심(배운 것) · 내 생각 · 새로 안 것 · 잘못 알던 것 · 몰랐던 것/더 팔 것 · 다음에 해볼 것
