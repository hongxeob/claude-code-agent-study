## 주요 기능 — Auto mode, Pro 플랜 지원

Auto mode 가 Pro 플랜에서도 동작하고 Opus 외에 Sonnet 4.6 도 지원한다. 권한 프롬프트를 매번 승인하는 대신 백그라운드 분류기가 판단해서, 일상적인 동작은 끊김 없이 실행되고 파괴적·수상한 동작은 차단되어 표면화된다. `--dangerously-skip-permissions` 처럼 전부 열지 않고도 중단 없이 작업할 수 있는 중간 지점이다.

```bash
claude update   # 업데이트 후 Shift+Tab 으로 모드 순환 시 auto mode 등장
```

계정 조건을 만족하면 프롬프트 하단에 `auto mode on` 이 표시된다.

관련 문서: https://code.claude.com/docs/en/permission-modes#eliminate-prompts-with-auto-mode

## 기타 변경

- `/usage` — 최근 사용량을 스킬·서브에이전트·플러그인·개별 MCP 서버 단위로 쪼개 보여준다. 무엇이 플랜 한도를 잡아먹는지 추적 가능 ([문서](https://code.claude.com/docs/en/costs#track-your-costs))
- `/code-review` — 정확성 버그를 보고하는 신규 커맨드. `/code-review high` 처럼 effort 지정, `--comment` 로 GitHub PR 인라인 코멘트 게시. `/simplify` 는 정리 전용 리뷰로 별도 유지 ([문서](https://code.claude.com/docs/en/code-review))
- "Extra usage" → "usage credits" 로 명칭 변경, `/extra-usage` → `/usage-credits` (구 이름도 동작). claude.ai 구독 로그인 필요, API 키 인증에서는 사용 불가
- 백그라운드 세션이 `/resume` 목록에 `bg` 표시로 함께 나오고, `claude agents` 에서 `Ctrl+T` 로 핀한 세션은 유휴 상태에서도 유지된다
- `claude agents --json` — 실행 중 세션을 JSON으로 출력(상태바·세션 피커 스크립팅용)
- Windows + Amazon Bedrock / Google Cloud Agent Platform / Microsoft Foundry 사용자는 PowerShell 도구가 기본 활성화. 해제는 `CLAUDE_CODE_USE_POWERSHELL_TOOL=0`
- `claude plugin disable` 은 다른 활성 플러그인이 의존하면 거부하고, `claude plugin enable` 은 전이 의존성까지 강제 활성화한다
- `/plugin` 마켓플레이스 탐색 화면이 예상 컨텍스트 비용을 표시하고, 설치 전에 해당 플러그인의 커맨드·에이전트·스킬·훅·MCP/LSP 서버 목록을 보여준다
- `worktree.bgIsolation: "none"` — 워크트리가 부적합한 레포에서 백그라운드 세션이 `EnterWorktree` 없이 작업 사본을 직접 수정하도록 허용
- 마크다운 출력이 GFM 체크박스를 렌더링하고, `/diff` 상세 뷰를 키보드로 스크롤 가능
- 상태줄 JSON 입력에 GitHub 레포·PR 정보가 포함된다
- Enterprise: `allowAllClaudeAiMcps` 관리 설정으로 `managed-mcp.json` 과 함께 claude.ai 클라우드 MCP 커넥터를 로드
