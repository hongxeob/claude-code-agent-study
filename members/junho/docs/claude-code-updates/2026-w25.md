## 주요 기능 — Artifacts

세션에서 claude.ai 의 비공개 URL로 발행하는 살아있는 인터랙티브 페이지. 세션이 계속 작업하면 그 자리에서 갱신된다. 터미널 텍스트가 적합하지 않은 산출물 — 예를 들어 diff 를 인라인 주석으로 붙인 PR 워크스루, 세션 데이터로 만든 대시보드 — 에 쓴다. 발행 시점 기준 Team·Enterprise 베타.

```text
Make an artifact that walks through this PR with the diff annotated inline.
```

> Week 27 에서 GA + Pro·Max 플랜 포함으로 확대됐다.

관련 문서: https://code.claude.com/docs/en/artifacts#create-an-artifact

## 주요 기능 — 입력 파라미터 기반 권한 매칭 (v2.1.178)

deny·ask 규칙이 `Tool(param:value)` 문법으로 도구의 입력 파라미터를 매칭한다. 예를 들어 `Agent(model:opus)` 는 Opus 티어를 요청하는 서브에이전트 스폰을 매칭한다. 값에 `*` 와일드카드 사용 가능(`Agent(isolation:*)`).

```json
{
  "permissions": {
    "deny": ["Agent(model:opus)"]
  }
}
```

관련 문서: https://code.claude.com/docs/en/permissions#match-by-input-parameter

## 주요 기능 — 프롬프트에서 설정 변경 (v2.1.181)

`/config key=value` 로 설정 화면을 열지 않고 바로 설정을 바꾼다. `-p` 비대화형 모드와 Remote Control 에서도 동작한다.

```text
/config thinking=false
```

관련 문서: https://code.claude.com/docs/en/commands#all-commands

## 기타 변경

- Auto mode 가 로컬 작업을 버리라고 지시하지 않은 상황에서 파괴적 git 명령(`git reset --hard`, `git clean -fd`, `git stash drop`)을 차단하고, 특정 스택을 지목하지 않은 `terraform destroy` 도 차단한다
- `attribution.sessionUrl: false` — 웹·Remote Control 세션의 커밋·PR에서 claude.ai 세션 링크를 생략
- `/config` 화면에서 Enter·Space 모두 선택 설정을 변경하고, Esc 는 되돌리기 대신 저장 후 닫기
- `sandbox.allowAppleEvents` 옵트인 설정 — macOS 에서 샌드박스 명령의 Apple Event 전송 허용
- `CLAUDE_CLIENT_PRESENCE_FILE` 에 마커 파일을 지정하면 사용자가 기기 앞에 있는 동안 모바일 푸시 알림을 억제한다
- 긴 문단이 첫 줄바꿈을 기다리지 않고 줄 단위로 스트리밍된다
- thinking 중 API 연결이 끊겨도 "Connection closed while thinking" 대신 자동 재시도
- `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` 이면 모든 세션이 암시적 팀 하나를 가지므로 Agent 도구의 `name` 파라미터로 팀원을 바로 스폰할 수 있다
- 중첩 `.claude/skills` 의 스킬이 해당 디렉토리 작업 시 로드된다. 이름이 충돌하면 중첩 스킬이 `<dir>:<name>` 으로 노출되어 둘 다 사용 가능
- 커스텀 `ANTHROPIC_BASE_URL` 및 Microsoft Foundry 에서 프롬프트 캐싱이 동작하지 않던 문제 수정
- 네트워크 드라이브·클라우드 동기화 폴더에서 Write·Edit 가 0바이트 또는 잘린 파일을 만드는 문제 수정
