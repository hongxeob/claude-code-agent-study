## 주요 기능 — CLI 에서 MCP 서버 인증 (v2.1.186)

`claude mcp login <name>` / `claude mcp logout <name>` 으로 대화형 `/mcp` 메뉴 없이 셸에서 MCP 서버를 인증한다. login 은 서버의 OAuth 플로우를 바로 실행하고, logout 은 저장된 자격증명을 삭제한다.

```bash
claude mcp login sentry
```

관련 문서: https://code.claude.com/docs/en/mcp#authenticate-from-the-command-line

## 주요 기능 — 셸 모드 출력에 Claude 가 응답 (v2.1.186)

`!` 접두사로 실행한 명령의 출력이 트랜스크립트에 들어오면 Claude 가 바로 응답한다. `! npm test` 만으로 실패 원인 설명까지 받을 수 있다(비용은 일반 프롬프트와 동일). 기존 동작(출력만 컨텍스트에 추가, 응답 없음)을 원하면 `settings.json` 에 `respondToBashCommands: false`.

```text
> ! npm test
```

관련 문서: https://code.claude.com/docs/en/interactive-mode#shell-mode-with-prefix

## 기타 변경

- `/rewind` 가 `/clear` 이전 지점으로 대화를 되돌릴 수 있다
- `sandbox.credentials` 설정 — 샌드박스 명령이 자격증명 파일·시크릿 환경변수를 읽지 못하게 차단
- 조직 모델 제한이 모델 피커, `--model`, `/model`, `ANTHROPIC_MODEL` 전부에 적용되고, 제한된 모델 선택 시 조직 설정에 의해 제한됐다는 메시지를 띄운다
- `autoMode.classifyAllShell` — 모든 Bash·PowerShell 명령을 auto mode 분류기로 보낸다. 거부 사유가 트랜스크립트·토스트·`/permissions` 에 표시된다
- `claude_code.assistant_response` OpenTelemetry 로그 이벤트 신규 — 모델 응답 텍스트를 담는다. 이미 프롬프트 내용을 로깅하던 배포는 업그레이드 시 자동 수신되므로, 프롬프트만 남기려면 `OTEL_LOG_ASSISTANT_RESPONSES=0`
- 백그라운드 서브에이전트가 권한 요청을 자동 거부하지 않고 메인 세션에 띄운다. 어느 에이전트가 요청하는지 표시되고 Esc 는 그 도구만 거부
- `/install-github-app` 이 GitHub App 설치만 하고 Actions 워크플로·시크릿 단계를 생략할 수 있다
- 샌드박스 네트워크 권한 대화상자에서 허용한 호스트를 세션 내내 기억한다(연결마다 재확인 안 함)
- 스트리밍 응답 CPU 사용이 약 37% 감소하고, 터미널 출력 캐시로 인한 장시간 세션 메모리 증가가 완화됐다
- `/review <pr>` 이 `/code-review medium` 과 같은 리뷰 엔진을 쓴다
- Bash 모드 `!` 명령에 실시간 파일 경로 자동완성 지원
