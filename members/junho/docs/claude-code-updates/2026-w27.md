## 주요 기능 — Claude Sonnet 5

Pro, Team Standard, Enterprise 구독 시트의 새 기본 모델. Sonnet 가격에 최상급 코딩·도구 사용 성능, 네이티브 1M 토큰 컨텍스트, adaptive thinking 기본 활성. API 가격은 8월 31일까지 프로모션 $2/$10 per MTok. v2.1.197 이상 필요.

```text
> /model claude-sonnet-5
```

관련 문서: https://code.claude.com/docs/en/model-config#available-models

## 주요 기능 — Claude in Chrome GA (v2.1.198)

Chrome 통합이 프리뷰를 벗어나 Anthropic 직접 플랜 사용자 전체에 공개됐다. Claude in Chrome 확장을 통해 탭을 열고, 페이지를 클릭하고, 폼을 채우고, 콘솔 로그를 읽고, 로그인 상태를 공유한다 — 만든 앱을 사용자가 컨텍스트를 바꾸지 않고도 테스트할 수 있다.

관련 문서: https://code.claude.com/docs/en/chrome

## 주요 기능 — 서브에이전트 기본 백그라운드 실행 (v2.1.198)

서브에이전트를 기다리며 대화를 멈추는 대신, Claude 가 계속 작업하다가 결과가 나오면 이어받는다. 결과가 먼저 필요한 경우엔 여전히 포그라운드로 실행하고, 백그라운드 서브에이전트의 권한 요청은 모두 메인 세션에 표시된다. 동작을 고정하려면 `background` frontmatter 필드를 쓴다.

관련 문서: https://code.claude.com/docs/en/sub-agents#run-subagents-in-foreground-or-background

## 주요 기능 — Claude Desktop on Linux (beta)

Ubuntu 22.04+, Debian 12+ (x86_64·arm64) 에서 데스크톱 앱 베타 제공. macOS·Windows 와 동일하게 Chat, Cowork, Claude Code — 병렬 세션, 비주얼 diff 리뷰, 통합 터미널·에디터, 라이브 앱 프리뷰. Anthropic apt 저장소에서 설치되므로 업데이트도 패키지 업데이트로 온다.

관련 문서: https://code.claude.com/docs/en/desktop-linux

## 주요 기능 — `/radio`

Claude FM lo-fi 라디오 스트림을 브라우저로 열고, 브라우저가 없으면 스트림 URL을 출력한다. Bedrock / Agent Platform / Foundry 에서는 사용 불가.


관련 문서: https://code.claude.com/docs/en/commands#all-commands

## 기타 변경

- [Artifacts](https://code.claude.com/docs/en/artifacts) GA — Team·Enterprise 에 이어 Pro·Max 플랜에도 포함
- 관리자가 콘솔에서 [조직 기본 모델](https://code.claude.com/docs/en/model-config#organization-default-model)을 지정할 수 있다. 사용자가 모델을 직접 고르지 않았으면 `/model` 에 "Org default" 로 표시
- `/skill-a /skill-b do XYZ` 처럼 스킬을 이어 붙이면 첫 번째만이 아니라 앞쪽 스킬 전부(최대 5개)를 로드한다
- `AskUserQuestion` 대화상자가 기본적으로 자동 진행하지 않는다. 유휴 타임아웃은 `/config` 에서 옵트인
- "default" 권한 모드 명칭이 CLI·`--help`·VS Code·JetBrains 전반에서 "Manual" 로 변경. `--permission-mode manual` 도 `default` 와 함께 허용
- `/dataviz` 스킬 신규 — 차트·대시보드 디자인 가이드와 실행 가능한 색상 팔레트 검증기 제공
- 내장 Explore 에이전트가 Haiku 대신 메인 세션 모델을 상속한다(Opus 상한)
- `claude agents` 에서 띄운 백그라운드 에이전트가 워크트리 코드 작업을 마치면 멈춰 묻지 않고 커밋·푸시·draft PR 생성까지 진행한다
- `code-reviewer` 같은 하이픈 포함 훅 매처가 부분 문자열 대신 정확히 일치한다. 하이픈 MCP 서버의 전체 도구를 매칭하려면 `mcp__brave-search__.*`
- 사용량 한도와 무관한 일시적 서버 rate-limit 오류는 구독자에게 백오프 자동 재시도된다
- 스트리밍 유휴 워치독이 모든 프로바이더에서 기본 활성 — 5분간 이벤트가 없으면 중단하고 재시도(`CLAUDE_ENABLE_STREAM_WATCHDOG=0` 로 해제)
