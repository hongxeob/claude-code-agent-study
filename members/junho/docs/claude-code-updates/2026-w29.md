## 주요 기능 — Artifacts 가 MCP 커넥터를 호출한다

발행된 artifact 가 열릴 때마다 MCP 커넥터를 호출할 수 있다. 대시보드가 세션 시점의 스냅샷이 아니라 실시간 데이터를 보여주고 즉석에서 액션까지 수행한다. 호출은 **보는 사람의 계정 연결**로 실행되고, 페이지의 첫 커넥터 호출 전에 열람자가 접근을 승인한다. 같은 주에 공개 공유 링크, Team·Enterprise 공동 편집용 editor 역할, Claude Tag 세션에서의 artifact 생성도 추가됐다.

```text
Build a dashboard artifact of open pull requests that pulls the live list through my GitHub connector when the page loads.
```

관련 문서: https://code.claude.com/docs/en/artifacts#pull-live-data-with-mcp-connectors

## 주요 기능 — 스크린 리더 모드

시각적 터미널 UI를 평문 선형 텍스트로 대체한다. 박스·스피너·제자리 다시 그리기 대신 라벨 붙은 줄을 순서대로 출력해 VoiceOver·NVDA 같은 스크린 리더가 읽을 수 있게 한다. 세션 단위는 플래그, 셸 단위는 `CLAUDE_AX_SCREEN_READER` 환경변수, 전역은 `axScreenReader` 설정.

```bash
claude --ax-screen-reader
```

관련 문서: https://code.claude.com/docs/en/accessibility#turn-on-screen-reader-mode

## 기타 변경

- `/fork` 가 대화를 새 백그라운드 세션으로 복사하고 `claude agents` 에 자기 행을 갖는다. 기존의 세션 내 fork 서브에이전트는 `/subtask` 로 분리
- [Auto mode](https://code.claude.com/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry) 가 Bedrock / Agent Platform / Foundry 에서 `CLAUDE_CODE_ENABLE_AUTO_MODE` 옵트인 없이 동작한다(관리자는 `disableAutoMode` 로 차단)
- 2분 넘게 걸리는 MCP 도구 호출이 자동으로 백그라운드로 넘어가 세션이 계속 쓸 수 있게 된다. 임계값 조정·해제는 `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`
- `claude auto-mode reset` — auto mode 설정을 기본값으로 복원. `--yes` 로 확인 생략
- [corporate launcher](https://code.claude.com/docs/en/corporate-launcher) 지원 — `CLAUDE_CODE_PROCESS_WRAPPER` 또는 `processWrapper` 설정으로 Claude Code 가 띄우는 프로세스(백그라운드 서비스, agents 뷰 세션 등)를 필수 래퍼 실행 파일을 통해 실행
- `vimInsertModeRemaps` 설정 — vim 모드에서 `jj` 같은 2키 입력 시퀀스를 Escape 로 매핑
- `--forward-subagent-text` / `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` — [stream-json 출력](https://code.claude.com/docs/en/headless)에 서브에이전트 텍스트와 thinking 블록 포함
- 폭주 방지용 세션 전역 상한: WebSearch 호출과 서브에이전트 스폰이 각각 기본 200회. `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`, `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION` 로 조정
- "Always allow" 권한 규칙이 레포 루트에 저장되어, 워크트리에서 승인한 내용이 세션·워크트리를 넘어 유지된다
- Amazon Bedrock, Google Cloud Agent Platform, Claude Platform on AWS 의 기본 모델이 Claude Opus 4.8 로 변경
- 접힌 도구 요약 줄에 실시간 경과 시간 카운터가 표시되어 오래 걸리는 호출이 멈춘 것처럼 보이지 않는다
