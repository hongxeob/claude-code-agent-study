## 주요 기능 — Claude Opus 4.8

Opus 4.8 이 Max, Team Premium, Enterprise pay-as-you-go, Anthropic API 의 기본 모델이 됐다. 기본 effort 가 high 이고, 더 어려운 작업엔 `/effort xhigh` 를 쓴다. v2.1.154 이상 필요.

```text
/model claude-opus-4-8
```

관련 문서: https://code.claude.com/docs/en/model-config#available-models

## 주요 기능 — Dynamic workflows (research preview)

워크플로는 Claude 가 작업에 맞춰 직접 작성해 여러 서브에이전트에 걸쳐 백그라운드로 실행하는 오케스트레이션 스크립트다. 한 대화로는 조율이 안 되는 규모 — 코드베이스 전역 감사, 대규모 마이그레이션, 교차 검증이 필요한 리서치 — 에 쓴다. 실행 관리는 `/workflows`.

```text
create a workflow that migrates every internal fetch() call to the new HttpClient wrapper
```

관련 문서: https://code.claude.com/docs/en/workflows

## 주요 기능 — security-guidance 플러그인

Claude 의 코드 변경을 취약점 관점으로 리뷰하고 같은 세션에서 고친다. 편집마다 빠른 패턴 검사, 턴 종료 시 모델 리뷰, 커밋·푸시 시 더 깊은 에이전틱 리뷰의 3단 구성. 프로젝트 규칙은 `.claude/claude-security-guidance.md` 에 추가한다.

```text
/plugin install security-guidance@claude-plugins-official
/reload-plugins
```

관련 문서: https://code.claude.com/docs/en/security-guidance

## 주요 기능 — Fast mode, Opus 4.8 기준

Fast mode 기본이 Opus 4.8 로 바뀌고 $10/$50 per MTok — 표준 요금의 2배로 약 2.5배 속도. Opus 4.7·4.6 은 $30/$150 유지, Opus 4.6 fast mode 는 폐기 예정.

```text
/fast
```

관련 문서: https://code.claude.com/docs/en/fast-mode#understand-the-cost-tradeoff

## 기타 변경

- `claude agents` 에서 셸 명령 앞에 `!` 를 붙이면 attach/detach 가능한 백그라운드 잡으로 실행. `claude --bg --exec 'pytest -x'` 로도 가능
- `.claude/skills` 디렉토리의 플러그인이 마켓플레이스 없이 자동 로드되고, `claude plugin init <name>` 이 새 플러그인을 스캐폴딩한다
- `/reload-skills` — 재시작 없이 스킬 디렉토리 재스캔. `SessionStart` 훅이 `reloadSkills: true` 를 반환하면 그 훅이 설치한 스킬을 같은 세션에서 쓸 수 있다
- 스킬·커맨드 frontmatter 에 `disallowed-tools` 를 지정해 스킬 활성 동안 특정 도구를 모델에서 제거할 수 있다
- `MessageDisplay` 훅 이벤트 신규 — 어시스턴트 메시지 텍스트를 표시 시점에 변형하거나 숨긴다
- 주 모델을 찾지 못하면 매 요청 실패하는 대신 세션 나머지 동안 `--fallback-model` 로 전환한다
- 플러그인이 `plugin.json` 또는 마켓플레이스 항목에 `defaultEnabled: false` 를 선언해 설치만 하고 꺼진 상태로 둘 수 있다
- Vim 모드: NORMAL 모드의 `/` 가 역방향 히스토리 검색 (Bash·Zsh vi-mode 와 동일)
- 스트리밍 도구 실행이 항상 활성 — 텔레메트리를 끈 경우와 Bedrock / Agent Platform / Foundry 에서도 동작
- `←←` 로 agents 뷰 열기가 Bedrock / Agent Platform / Foundry, 텔레메트리 비활성 환경에서도 동작
- Claude in Chrome: `/chrome` → "Select browser…" 로 연결된 브라우저 중 사용할 것을 고른다. 여러 개 연결 시 대화 중에도 선택 가능
- `claude mcp list` / `claude mcp get` 이 출력 파이프 시 미승인 `.mcp.json` 서버를 자동 승인·연결하지 않고 승인 대기로 표시한다
