## 주요 기능 — `/cd` 로 세션 이동 (v2.1.169)

프롬프트 캐시를 다시 만들지 않고 현재 세션의 작업 디렉토리를 옮긴다. 새 디렉토리의 `CLAUDE.md` 는 시스템 프롬프트를 교체하는 대신 메시지로 덧붙는다. 세션은 새 디렉토리의 프로젝트 저장소로 이동하므로 `--resume`·`--continue` 도 거기서 찾는다. 처음 작업하는 디렉토리면 신뢰 확인을 요청한다.

```text
> /cd ../other-project
```

관련 문서: https://code.claude.com/docs/en/commands#all-commands

## 주요 기능 — 서브에이전트가 서브에이전트를 띄운다 (v2.1.172)

서브에이전트가 자기 서브에이전트를 스폰할 수 있다. 프롬프트 아래 패널이 전체 트리를 보여주고, 각 행에 하위 개수와 `main` 까지의 경로가 표시된다. 폭주 방지를 위해 체인은 5단계로 제한된다.

```text
> /agents
```

관련 문서: https://code.claude.com/docs/en/sub-agents#let-subagents-spawn-their-own-subagents

## 주요 기능 — safe mode 로 설정 문제 격리 (v2.1.169)

`--safe-mode` 또는 `CLAUDE_CODE_SAFE_MODE` 로 모든 커스터마이즈를 끈 상태로 시작한다 — `CLAUDE.md`, 스킬, 플러그인, 훅, MCP 서버, 커스텀 커맨드·에이전트가 로드되지 않는다. 인증·모델 선택·기본 도구·권한은 그대로 동작하므로, safe mode 에서 문제가 사라지면 원인은 커스터마이즈 쪽이다.

```bash
claude --safe-mode
```

관련 문서: https://code.claude.com/docs/en/debug-your-config#test-against-a-clean-configuration

## 기타 변경

- [`fallbackModel`](https://code.claude.com/docs/en/model-config#fallback-model-chains) — 주 모델이 과부하·불가일 때 순서대로 시도할 폴백 모델 최대 3개 설정. `--fallback-model` 이 대화형 세션에도 적용된다
- 세션 제목이 대화 언어로 생성된다. 특정 언어로 고정하려면 `language` 설정
- `claude agents --json` 에 `--all`(완료 세션 포함)과 `id`·`state` 필드 추가. 차단·신규 디스패치 세션도 누락되지 않는다
- `/plugin` 의 마켓플레이스 탐색에 검색 바 추가
- `disableBundledSkills` 설정과 `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` 로 번들 스킬·워크플로·내장 커맨드를 모델에서 숨긴다
- deny 규칙의 도구 이름 위치에 글로브 사용 가능 — `"*"` 로 전체 도구 차단. 알 수 없는 도구 이름은 시작 시 경고
- 세션 간 메시징 강화: 다른 세션에서 `SendMessage` 로 전달된 메시지는 사용자 권한을 갖지 않고, auto mode 는 이를 차단한다
- Amazon Bedrock 이 `AWS_REGION` 미설정 시 `~/.aws` 설정 파일에서 리전을 읽고, `/status` 가 리전 출처를 표시한다
- `enforceAvailableModels` 관리 설정 — `availableModels` 허용목록이 Default 모델에도 적용되게 한다
- Claude in Chrome 브라우저 도구가 도구별 개별 호출 대신 한 번의 배치 호출로 로드된다
- `claude update` 가 다운로드 전에 대상 버전을 알려준다
- `footerLinksRegexes` 설정 — 정규식으로 매칭된 링크 배지를 푸터에 추가
