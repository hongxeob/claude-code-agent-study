## 주요 기능 — Auto mode, 서드파티 프로바이더 지원 (v2.1.158)

Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry 에서도 Opus 4.7·4.8 로 auto mode 를 쓸 수 있다. 옵트인 후 Shift+Tab 으로 모드 순환.

```bash
export CLAUDE_CODE_ENABLE_AUTO_MODE=1
```

> Week 29 에서 이 옵트인 변수는 불필요해졌다.

관련 문서: https://code.claude.com/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry

## 주요 기능 — 자동 편집 안전장치 (v2.1.160)

`acceptEdits` 모드에서도 **코드를 실행시킬 수 있는 파일**을 쓸 때는 확인을 받는다. 보호 대상은 `.zshenv`·`.bash_login` 같은 셸 시작 파일, `~/.config/git/` 하위 git 설정, `.npmrc`·`.bazelrc`·`.pre-commit-config.yaml` 같은 빌드 도구 설정. `bypassPermissions` 를 제외한 어떤 모드에서도 자동 승인되지 않는다.

```bash
claude --permission-mode acceptEdits
```

관련 문서: https://code.claude.com/docs/en/permission-modes#protected-paths

## 주요 기능 — `/plugin list` (v2.1.163)

`/plugin` 메뉴를 열지 않고 설치된 플러그인을 인라인 출력한다. 셸에서는 `claude plugin list`. 대화형에서는 `--enabled` / `--disabled` 로 상태 필터링.

```text
> /plugin list --enabled
```

관련 문서: https://code.claude.com/docs/en/plugins-reference#plugin-list

## 주요 기능 — 관리 배포용 버전 요구사항 (v2.1.163)

`requiredMinimumVersion`, `requiredMaximumVersion` 관리 설정으로 조직이 허용 버전 범위를 강제한다. 범위 밖 클라이언트는 시작 시 종료되며 조직 방식으로 업데이트하라는 안내를 띄운다. `claude update`, `claude install`, `claude doctor` 는 계속 동작해 복구가 가능하다.

```json
{
  "requiredMinimumVersion": "2.1.163"
}
```

관련 문서: https://code.claude.com/docs/en/admin-setup#decide-what-to-enforce

## 기타 변경

- [dynamic workflows](https://code.claude.com/docs/en/workflows) 트리거 키워드가 `workflow` → **`ultracode`** 로 변경(자기 말로 요청해도 동작). 프롬프트에서 보라색으로 강조된다
- [Stop·SubagentStop 훅](https://code.claude.com/docs/en/hooks)이 `hookSpecificOutput.additionalContext` 를 반환하면 에러 취급 대신 Claude 에 피드백을 주고 턴을 이어간다
- `claude mcp` list/get/add 가 비밀값을 출력하지 않는다 — 환경변수 참조는 확장하지 않고, 인증 헤더·URL 시크릿은 마스킹
- 병렬 도구 배치에서 Bash 명령 하나가 실패해도 나머지가 취소되지 않고 각자 결과를 반환한다
- 단일 파일 `grep`/`egrep`/`fgrep` 으로 본 파일은 편집 전 별도 Read 가 필요 없다
- 자동완성 메뉴에서 커맨드를 클릭하면 즉시 실행되지 않고 프롬프트에 채워진다(Enter 로 실행)
- `--tools` 에 `Grep`·`Glob` 을 지정하면 검색 내장 네이티브 빌드에서 전용 검색 도구를 제공한다(기존엔 무시)
- `/effort` 가 선택한 레벨이 새 세션 기본값으로 유지되는 경우 이를 알려준다
- `OTEL_RESOURCE_ATTRIBUTES` 값이 메트릭 데이터포인트 라벨로 붙어 팀·레포 같은 커스텀 차원으로 사용량을 나눠 볼 수 있다
- `/ide`, `/terminal-setup`, `/scroll-speed` 에서 Windsurf → Devin Desktop 으로 명칭 변경
- `/btw` 에 `c to copy` 단축키 추가 — 원본 마크다운 답변을 클립보드로 복사
