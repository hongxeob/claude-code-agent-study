## 주요 기능 — Desktop 내장 브라우저

데스크톱 앱의 Claude Code 에 브라우저가 내장됐다. 문서·디자인 등 아무 사이트나 열어 로컬 개발 서버 프리뷰처럼 읽고 클릭하고 조작할 수 있다. 브라우저는 샌드박스이며 설정 가능 — 브라우징 세션 유지 여부를 고르고, 외부 사이트에서의 동작은 안전 분류기가 검토한다.

관련 문서: https://code.claude.com/docs/en/desktop#browse-external-sites

## 주요 기능 — `/doctor` 가 전체 설정 점검으로 (v2.1.205)

읽기 전용 리포트를 출력하던 `/doctor` 가 문제를 진단하고 고칠 수 있게 됐다. 설치 상태 점검, 컨텍스트 비용 대비 안 쓰는 스킬·MCP 서버·플러그인 탐지, 로컬 `CLAUDE.md` 와 커밋된 파일의 중복 제거, 코드베이스에서 유추 가능한 `CLAUDE.md` 내용 정리 제안, 느린 훅 표시. 변경 전에 발견 사항을 먼저 보고하고 확인을 받는다. `/checkup` 은 별칭.

```text
> /doctor
```

관련 문서: https://code.claude.com/docs/en/commands#all-commands

## 기타 변경

- Auto mode 가 세션 트랜스크립트 파일 조작을 차단하고, 컨텍스트에서 값을 확정할 수 없는 변수에 대한 `rm -rf` 실행 전에 확인을 받는다
- `/cd` 가 `/add-dir` 처럼 입력 중 디렉토리 경로를 제안한다
- `/commit-push-pr` 이 `origin` 외에 레포에 설정된 push 원격에도 `git push` 를 자동 허용한다
- Gateway: `/login` 이 Anthropic 운영 공용 게이트웨이 엔드포인트를 지원
- `EnterWorktree` 가 프로젝트 `.claude/worktrees/` 밖 워크트리로 진입할 때 확인을 받는다
- 백그라운드 에이전트가 Claude Code 업데이트 직후 백그라운드로 새 버전으로 올라간다(attach 할 때 느린 stale 세션 업그레이드를 겪지 않음)
- agents 뷰 행이 원시 도구 호출 텍스트 대신 색상 상태 단어와 분류기가 쓴 헤드라인을 보여주고, 기존 PR을 편집·머지·코멘트·푸시한 세션은 `claude agents` 에서 해당 PR을 링크한다
- 자동 업데이트 바이너리 다운로드가 메모리 버퍼링 대신 디스크로 스트리밍되어 업데이터 피크 메모리가 약 400MB 감소
- 백그라운드 작업 알림이 "사람 입력이 없었음"을 명시해, 트랜스크립트 내 조작된 승인이 실행되는 것을 방지
- Opus 4.8 의 `/code-review` 발견 품질이 모든 effort 레벨에서 개선
