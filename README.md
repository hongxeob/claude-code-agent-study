# claude-code-agent-study

클로드 코드(Claude Code)로 실전 에이전틱 코딩을 함께 공부하는 스터디 레포입니다.

## 목적

- 책을 통해 **AI 도구들이 내부적으로 어떻게 동작하는지 제대로 이해**합니다.
- AI 산출물을 그대로 받아들이거나 단순 검증에 그치지 않고, **문제를 제대로 정의하고 스스로 해결·검증할 수 있는 사고력**을 기릅니다.
- AI를 사고를 대신하는 도구가 아니라, **더 깊이 사고하기 위한 도구**로 활용합니다.

## 교재

[클로드 코드로 시작하는 실전 에이전틱 코딩](https://product.kyobobook.co.kr/detail/S000219929026)

## 진행 방식

- 교재를 기반으로 진행하며, 매주 실습 과제와 결과물을 이 레포에 공유합니다.
- **매주 수요일 21:00**에 시작합니다.
- 모임은 **Google Meet**으로 진행합니다.
- 회의록은 **Gemini "회의록 작성"(Take notes for me)** 기능으로 작성하여 [`meeting-notes/`](./meeting-notes/) 폴더에 정리·보관합니다.
- 매주 **리더를 돌아가며** 맡습니다. 리더는 그 주 챕터에 맞는 부가 리딩을 준비하고, 모임 중 최신 AI 동향과 알아온 것을 공유합니다.
- 도구·환경은 **Claude 환경으로 통일**합니다.

### 운영 원칙

- **타이머를 맞춰두고 정해진 시간 안에** 그날 목표한 바를 끝내는 것을 목표로 합니다.
- 단순히 시간만 채우는 게 아니라, **양질의 결과물**로 마무리하는 것을 지향합니다.
- 스터디는 **약 3개월 내 마무리**를 목표로 합니다.
- 책 진도는 요약이 아니라, **1인당 약 10분** 발표로 핵심 내용·본인 생각·새로 알게 된 점·잘못 알고 있던 점을 공유합니다.

## 스터디 흐름

한 주는 **모임 전 각자 준비 → 수요일 1시간 모임**으로 돌아갑니다. 스킬은 이 흐름에 맞춰 [`.claude/skills/`](./.claude/skills/)에 **모임 전(`pre-`) / 모임 중(`mid-`)** 으로 나눠 둡니다.

### 모임 전 (각자)

- 그 주 챕터를 **자기 언어로** 정리하고, `pre-chapter-prep`으로 **정리본(md) + 발표 자료(html 한 장)**를 만든다. (책 베끼기가 아니라 본인 이해·경험 중심, 역질문으로 스스로 검증)
- **리더**는 그 주 챕터에 맞는 **부가 리딩**(배경 자료·심화)을 따로 준비한다.
- 다음 실습 주제가 필요하면 `pre-chapter-ideas`로 후보를 뽑아 3인이 나눈다.

### 모임 (수 21:00 · 1시간)

| 시간 | 내용 |
|------|------|
| 00–30분 | **발표** — 1인 10분씩 ×3. 각자 html·md로, 책 요약보다 **본인 생각·경험** 중심 (요약 : 생각 ≈ 8 : 2) |
| 30–40분 | **통합** — `mid-chapter-merge`로 3개 정리본을 하나로 합쳐 그 주 `chapters/chN/README.md`로 등록 |
| 40–50분 | **리더 공유** — 리더가 준비한 최신 동향·부가 리딩 공유 |
| 50–60분 | **회고** — `mid-study-wrapup` 결과를 보며 실제 회고 (사실→성찰→액션 + 팀 KPT) |

> 발표가 끝나는 **30분 시점에 Gemini 회의록을 추출해 `mid-study-wrapup`을 돌려둔다.** 통합·리더 공유가 진행되는 동안 결과가 나오고, 마지막 10분에 그걸 보며 회고한다.

## 공통 스킬

논의로 추린 스킬을 [`.claude/skills/`](./.claude/skills/)에 모임 전(`pre-`) / 모임 중(`mid-`) / 상시로 나눠 둡니다. 상세·사용법은 링크 참고.

- **모임 전** — `pre-chapter-prep`(챕터 노트 → 정리본 md + 발표 html), `pre-chapter-ideas`(챕터 → 실습 주제 후보)
- **모임 중** — `mid-chapter-merge`(3인 정리본 → 그 주 결과물), `mid-study-wrapup`(회의록 → 회고 베이스)
- **상시** — `tell-me-about-claude-code`(키워드 공식문서 설명), `update-claude-code-docs`(주차별 업데이트 축적)

## 커리큘럼

### 1주차

스터디에 필요할 것 같은(또는 스터디 중 생길 법한 문제를 해결해 줄 수 있는) **플러그인/스킬을 각자 2~3개씩** 만들어 옵니다.

- 예: 주제 선정·회고·의사결정 지원 도구, 반복 작업 자동화 스킬 등
- 각자 만든 도구는 목적 / 사용법 / 예시를 함께 정리해 공유
- 다음 모임에서 **각자 제작한 도구를 시연**하고, 책 1개 챕터 학습을 병행합니다.
- 개인별 산출물은 각자 폴더에 정리합니다 — [홍섭](./members/hongseob/) · [재윤](./members/jaeyoon/) · [준호](./members/junho/)
- 각자 만든 스킬 중 논의를 거쳐 추린 것은 [`.claude/skills/`](./.claude/skills/)에 **공통 스킬**로 승격해 팀 전체가 사용합니다.
- AI·클로드 코드·에이전틱 코딩 관련해 얻은 인사이트는 [`insight/`](./insight/)에 자유롭게 메모·공유합니다.

---

> 이후 커리큘럼은 확정되는 대로 업데이트됩니다.

## 레포 구조

```
chapters/ch1~ch7/    # 교재 장별 학습 메모·실습
members/<이름>/      # 각자 제작한 플러그인/스킬 (개인 작업 공간)
.claude/skills/      # 논의로 추린 공통 스킬 (팀 전체 사용)
insight/             # AI·에이전틱 코딩 인사이트 메모·공유
meeting-notes/       # Gemini 회의록
```
