# chapter-merge — 개인 정리본 → 그 주 챕터 결과물

각자(chapter-prep로 만든) 개인 정리본 여러 개 → **챕터 README(md) + 통합 발표 HTML 한 장**(팀 결과물).
개인별 정리는 chapter-prep, 통합은 이 스킬. 둘은 다른 단계.

## 입력

- 참여자들의 개인 정리본: `chapters/chN/*/정리본.md` (전원 것 자동 수집) 또는 경로 목록.
- 챕터 번호/제목.

## 절차

1. 각 정리본을 읽는다.
2. **참여자별 섹션 보존** — 각자 발표 개념 + **경험·생각**을 사람별로 그대로 싣는다. (단순 책 정리 아님 — 개인 경험·생각이 핵심. 뭉개기 금지)
3. **고정 렌즈로 종합** — 아래 4개 렌즈로만 묶는다 (매주 동일, 주차 간 비교되게). 정리본에 실제로 있는 내용만 근거 (새 주장 금지):
   - **공통**: 셋 다 짚은 것
   - **흥미로운 것**: 인상 깊었던 개념·경험 (누가 뭘 흥미로워했나)
   - **갈린 관점**: 같은 걸 서로 다르게 본 것
   - **팀이 더 팔 것**: 각 정리본의 역질문·`(확인 필요)`·궁금 모음
4. `chapters/chN/README.md`로 저장. `chapters/_TEMPLATE.md`가 있으면 그 틀을 따른다. 다른 참여자 섹션을 임의로 바꾸지 않는다.
5. **통합 발표 HTML** `chapters/chN/발표-통합.html` 생성 — 위 README와 같은 내용을, 참여자별 관점을 **좌우 2열/카드로 대비**한 자체완결 한 장(인라인 CSS/JS, 외부 요청 0, 반응형). PPT 넘김 금지.

## 규칙

1. **개인 통찰은 원문 보존.** 종합한답시고 개인 생각을 뭉개거나 대표 하나로 덮지 마라.
2. **렌즈 4개는 고정** (공통/흥미로운 것/갈린 관점/팀이 더 팔 것). 매주 바꾸지 마라 — 주차 간 비교가 목적.
3. 렌즈 종합은 **정리본에 있는 것끼리만**. 없는 사실·평가 지어내기 금지. 참여자별 섹션은 압축이 아니라 정리.
4. HTML은 자체완결 — 외부 스크립트/폰트/이미지 요청 금지. 인라인만. README와 내용 일치.
5. 저장 전 기존 파일 있으면 덮어쓰기 확인.

## 출력 구조 (챕터 README)

```
# chN — <챕터 제목>

## 참여자별   (원문 보존)
### 홍섭 — <발표 개념>
- 개념 요점 / 내 경험·생각 ...
### 재윤 — <발표 개념>
- ...
### 준호 — <발표 개념>
- ...

## 공통          (셋 다 짚은 것)
- ...
## 흥미로운 것    (인상 깊었던 개념·경험)
- ...
## 갈린 관점      (같은 걸 다르게 봄)
- ...
## 팀이 더 팔 것  (미해결·궁금)
- (각 정리본 역질문 모음)
```

**렌즈 4개(공통/흥미로운 것/갈린 관점/팀이 더 팔 것)는 매주 고정.**
통합 HTML(`발표-통합.html`)은 같은 구조를 화면용으로: 참여자별 카드 대비 + 4렌즈 블록.

## 산출물

- `chapters/chN/README.md` (그 주 결과물, 커밋 대상)
- `chapters/chN/발표-통합.html` (자체완결 한 장, 브라우저로)
