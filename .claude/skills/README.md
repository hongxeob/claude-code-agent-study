# 공통 스킬 (Shared Skills)

각자 `members/`에서 만들어 온 스킬 중, **논의를 거쳐 추린 것들을 공통 스킬로 승격**해 이 폴더에 둡니다. 여기 있는 스킬은 이 레포에서 클로드 코드로 작업할 때 팀 전체가 함께 사용합니다.

## 분류: 모임전 / 모임중 (접두사)

셋의 스킬이 다 들어오면 이름만 봐선 헷갈립니다. 그래서 **스터디 흐름상 언제 쓰는지**로 나누고, 스킬 이름에 접두사를 붙입니다.

| 접두사 | 그룹 | 시점 | 성격 |
|--------|------|------|------|
| `pre-` | **모임 전** | 각자 모이기 전에 돌림 | 개인 준비 |
| `mid-` | **모임 중** | 21:00 모임 진행 중 | 팀 작업 |
| _(없음)_ | **상시** | 시점 무관 | 공식문서 조회 등 참고 도구 — 원래 이름 유지 |

> **왜 폴더가 아니라 접두사인가**: 클로드 코드 스킬 탐색은 `.claude/skills/<이름>/SKILL.md` 한 단계만 본다. `.claude/skills/모임전/...`처럼 폴더로 묶으면 스킬로 인식이 안 된다. 그래서 폴더는 flat하게 두고 이름 접두사로 그룹을 표시한다.

## 스킬 맵

1시간 모임 루틴(발표 30분 → 통합 10분 → 리더 공유 10분 → 회고 10분)에 맞춘 배치:

### `pre-*` 모임 전 (개인)

| 스킬 | 하는 일 |
|------|---------|
| `pre-chapter-prep` | 본인 챕터 노트 → 개인 정리본 md + 발표 html 한 장 (역질문 게이트) |
| `pre-chapter-ideas` | 다음 챕터 개념 → 실습 주제 후보 추천 + 3인 분배 |

### `mid-*` 모임 중 (팀)

| 스킬 | 하는 일 |
|------|---------|
| `mid-chapter-merge` | 개인 정리본 3개 → 그 주 챕터 결과물 (README + 통합 발표 html) |
| `mid-study-wrapup` | 발표·토의 회의록 → 마지막 10분 회고 베이스 (개인 사실·성찰·액션 + 팀 KPT) |

> 위 4개는 홍섭이 `members/hongseob/`에서 만든 걸 접두사 붙여 승격한 것. 팀 논의로 계속 다듬는다.

### 상시 (모임과 무관 · 접두사 없음)

| 스킬 | 하는 일 |
|------|---------|
| `tell-me-about-claude-code` | 키워드를 공식문서 근거로 한국어 설명 (`/tell-me-about-claude-code <키워드>`) |
| `update-claude-code-docs` | 공식 What's New 주차 다이제스트 축적 (`/update-claude-code-docs`) |

> 준호가 만든 슬래시 전용(`disable-model-invocation`) 스킬. 특정 모임 시점에 안 묶여 접두사 없이 이동. `update-claude-code-docs` 출력은 `members/junho/docs/claude-code-updates/`에 그대로 쌓인다.

## 구조

```
.claude/skills/
  pre-<skill-name>/
    SKILL.md      # 모임 전 스킬
  mid-<skill-name>/
    SKILL.md      # 모임 중 스킬
```

## 승격 절차

1. 각자 `members/<이름>/`에서 스킬 제작 (개인 이름으로).
2. 모임에서 논의 → 공통으로 쓸 스킬 선정.
3. 선정된 스킬을 `pre-`/`mid-` 접두사 붙여 `.claude/skills/<접두사-이름>/`로 이동. (상시 참고 스킬은 접두사 없이 원래 이름)
4. PR로 통합 관리.
