# chapter-prep — 팀원용 안내

스터디 **모이기 전, 본인이** 정리한 챕터 노트(md)를 넣으면 **개인 정리본 md → 발표용 HTML 한 장**을
순서대로 만들어주는 스킬 (1인 10분 발표용, 사람별). 먼저 정리본을 만들고 역질문에 답해 **확정한 뒤**,
그 정리본으로 발표 자료를 만든다. (깨끗한 정리본이 있어야 깨끗한 발표 자료가 나옴 · HTML은 스크롤 한 페이지)

> 3명 것을 하나로 합치는 "그 주 챕터 결과물"은 이 스킬이 아니라 별도 통합 스킬 몫.

> 만든 사람: 홍섭 · 스킬 본체: [`SKILL.md`](./SKILL.md)

## 통찰은 사람이

정리본은 **첨삭·구조화만** 한다. 애매하거나 빈틈인 부분은 AI가 채우지 않고
**역질문**으로 던진다 → 사람이 답해야 정리본이 확정된다. (요약 대신하기 방지)

## 쓰는 법

1. **본인** 챕터 정리 md를 준비 (`chapters/chN/` 아래나 붙여넣기).
2. "발표 준비" / "발표 자료 만들어" 트리거 + 파일 경로/챕터번호/이름 전달.
3. **정리본 초안 + 역질문 목록**이 나온다.
4. **역질문에 답한다 → 정리본 확정.** (이걸 해야 다음으로 넘어감)
5. 확정 정리본으로 **발표용 HTML 한 장** 생성.
6. `chapters/chN/<이름>/발표.html`을 브라우저로 열어 발표.

## 특징

- **적용예시 실측**: 각 개념을 내 `~/.claude/**` 실제 설정에서 확인해 붙임 (추정 금지, 없으면 "아직 없음").
- 블랙박스/화이트박스 비교가 챕터에 있으면 **좌우 대비로 시각화**.
- HTML은 자체완결(오프라인 열림, 외부 요청 없음).
